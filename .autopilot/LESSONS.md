# Lessons

What earlier builds learned the hard way, here and in other projects. Act on every line that applies to the work in front of you.

## Every project on this machine
- 2026-10-28 tdd-check prints NO TESTS when tests live in a check-parts directory it does not recognise -> have the reviewer verify tests fail on base by reading them (from DSA App)
- 2026-10-28 reviewers that try git --work-tree checkouts are refused by the auto-mode classifier -> tell reviewers to use git show and git diff only (from DSA App)
- 2026-10-28 parallel agents driving the desktop browser pane exceed its tab cap -> run one browser-pane agent at a time; headless Playwright in separate lanes (own ports) may run in parallel (from DSA App)
- 2026-10-28 a conductor that blocks in ap wait loops while agents run burns a full-context turn per wake and cannot hear the user -> end the turn after dispatch and let agent completion notifications wake it (from shelf-this)
- 2026-10-28 this VPS: user dev has passwordless sudo and the docker group; /opt apps are root-owned -> use sudo for /opt deploys, keep new tool installs user-level in ~/.local (from autopilot setup)
- 2026-10-28 the full ECC plugin adds ~47k tokens to every session and subagent -> keep ECC lean (copied skills) and check claude plugin details before enabling any big plugin (from autopilot setup)
- 2026-10-28 usage limit burned to 85% in one session with many parallel agents and runner agents for shell work -> cap at 5 agents in flight, run merges/gates/pushes as plain Bash (ap merge), one plan reviewer, one fix round (from shelf-this)
- 2026-10-28 transcribing a 2-minute phone recording with 4 parallel image-reading agents cost ~500k tokens -> sample frames at 1 fps, read only the slices that matter (start and end), and use at most 2 agents (from shelf-this)
- 2026-10-28 session-only CronCreate timers die when the VPS is powered off (the hosting provider restarted it via the QEMU guest agent) -> for an unattended resume use a durable mechanism (systemd user timer or crontab); auto-reboot settings do not prevent it (from shelf-this)
- 2026-10-28 playwright install-deps fails under 'sudo pnpm' (pnpm not on root's PATH) -> run 'sudo env PATH=$PATH web/node_modules/.bin/playwright install-deps chromium' once per VPS (from shelf-this)
- 2026-10-28 a bash wait loop using pgrep -f '<pattern>' matches its own command line and waits forever -> serialize with a lock (ap merge takes .autopilot/merge.lock) instead of pgrep polling (from shelf-this)
- 2026-10-28 4-core VPS that also serves production: 5 lanes of compose+pytest+Vite+Chromium pushed load to ~14 -> cap lanes at 3, give test containers cpu_shares 256 and run gate/e2e host work under nice -n 10 (from shelf-this)
- 2026-10-28 planner fills Skills from find ~/.claude -name SKILL.md, which lists disabled plugin copies (ECC) -> take skill names only from the session skill list or enabledPlugins (from shelf-this)
- 2026-10-28 planner puts a rate limit only in Notes -> give it an acceptance criterion with a non-default key function and prove a second key is unaffected (from shelf-this)
- 2026-10-28 a new package named like an ignored path (secrets/) is silently left untracked and tests pass only in the lane -> after adding a package, git ls-tree the branch for it, or check-ignore -v (from shelf-this)
- 2026-10-28 a replay/dedup key is set with a TTL equal to the signature tolerance (F7: EX 300 vs a signature valid ts-300..ts+300) -> size the TTL to the full validity span (exat=ts+tolerance+1) and test with ts=now+tolerance-1 (from shelf-this)
- 2026-10-28 an idempotency key is written before the work (F7: key kept after a 500, so the sender's retry got 409 with nothing imported) -> release the key on every non-deterministic failure, keep it only for deterministic rejections, and test the 500-then-retry path (from shelf-this)
- 2026-10-28 any non-default tmux server loads ~/.tmux.conf (resurrect/continuum) and relaunches real claude sessions -> start every test/e2e tmux server with -f /dev/null and assert containment, not equality, on 'empty' servers (from claude-app)
- 2026-10-28 vitest/e2e runs sharing one tmux socket kill each other, and 'passes alone, fails concurrently' recurred through verify (F2 gate, UI reviewer killed l0) -> give every run a unique socket suffix and unique session names from the first task, and treat that symptom as an isolation bug, not a timeout (from claude-app)
- 2026-10-28 test scratch dirs in /tmp (tmpfs 7.9G) leaked ~60k dirs and a merge gate failed with EDQUOT -> tests create scratch through one helper that removes it in afterAll, and run df -h /tmp before each gate (from claude-app)
- 2026-10-28 scan-diff P0 hardcoded-credential fires on a constant named with PASSWORD/SECRET even for public test values (F7 merge undone) -> name test constants FAKE_E2E_* with no credential keyword, and put 'fake' in the matched text (from claude-app)
- 2026-10-28 CI had never run before the PR and cost 4 rounds (browser missing in gate job, HOME-dependent test, runner-timing ws tests, systemd-analyze on target-only path, tmux locale, full chromium, workflow-pinning test) -> in verify, before opening the PR, run the CI workflow steps once in a clean env (env -i, empty HOME, no browser cache, LANG unset) AND once with 2 CPU hogs running beside it (clean env alone missed the load-dependent tests, 3 more CI rounds); when a task touches the workflow, brief the coder to run tests/ci too, never 'no vitest needed' (from claude-app)
- 2026-10-28 builders/reviewers ran git checkout in the main checkout twice, moving the conductor's branch -> brief every agent: stay in the lane worktree, read other branches with git show/diff only, never checkout in /home/dev/src/claude-app (from claude-app)
- 2026-10-28 a merge started in a detached subshell is invisible to the harness and its result is lost; a bash -c script containing rm is refused by the classifier -> start merges/gates with run_in_background and call rm separately with absolute literal paths (from claude-app)
